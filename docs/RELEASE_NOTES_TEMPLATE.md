## Overview

A single-player space sandbox with ship control, exploration, fitting, trade, production, missions, fleets and a persistent local simulation.

## Included in this version

- Consolidated Q01–Q07 gameplay systems and earlier A–P foundations.
- DesktopGL ship fitting, star map, scanning, commerce, industry and station interfaces.
- Data-driven ships, multi-LOD procedural models, extensive galaxy/spatial content.

## Install

1. Download the Windows x64 ZIP attached to this release.
2. Extract **every** file to a new folder. Keep the `Assets/` directory with the executable.
3. Run `StarlightSyndicateDemo.exe`.

Before upgrading, back up `%LOCALAPPDATA%\StarlightSyndicateDemo` (especially any `save-3d.json` or `save-universe43.json` files). Existing save schema is 54, but migration should be tested for the release being published.

## Known limitations

- This is a work in progress, not a finished 1:1 replica of any other game.
- Some content, NPC behavior, prices, rewards, legal systems and interfaces use local authored implementations.
- See `docs/FEATURES.md` for subsystem detail.
