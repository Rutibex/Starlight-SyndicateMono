# Community code of conduct

The project welcomes respectful technical discussion, constructive criticism and contributions. Be considerate to other contributors, avoid harassment, targeted insults, spam and discriminatory abuse, and discuss code and gameplay decisions in good faith.

Maintainers may edit, hide or close discussions that violate these expectations. To report a concern, contact the repository maintainers through an appropriate private GitHub channel when available. The project does not presently designate a separate private contact address.
