# Security policy

Starlight Syndicate is an offline, experimental single-player game, not a networked production service. There is no guaranteed security-support lifetime or response SLA for this development build.

For a vulnerability, prefer GitHub's **Report a vulnerability** / private vulnerability reporting function if it is enabled for the repository. Otherwise, open a minimal issue **without** sensitive exploit details and request a private contact route from the maintainer. Do not post authentication secrets, private paths or other players' data.

Dependency and platform updates must be tested against MonoGame and the game before a public distribution is made. See [Release checklist](docs/RELEASE_CHECKLIST.md).
